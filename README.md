# personal-website

Static personal site for Ryan Appuhamy — plain `index.html`, no framework, no build step.

- **Live:** https://ryanappuhamy.vercel.app
- **Contents:** `index.html`, `CV_Ryan_Appuhamy.pdf`, `thesis.pdf`

## Deploy

Hosted on Vercel. Every push to `main` triggers a production deployment automatically.
Manual deploy: `vercel --prod`.
